# Zen Agent — 设计原则

> 禅模式不是"极简 UI"，而是 **Minimal User Decisions**。
> 把 Agent 的复杂性隔离在系统内部，把人的注意力留给事情本身。

## 核心模型

UX 建立在唯一循环上：

**交代 → 离开 → 回来 → 判断 → 必要时介入**

而不是 ChatGPT 式"输入 → 等待 → 看过程 → 再输入"。

Agent 是**被委托的工作者**，不是聊天对象。用户进入禅模式后的第一感受应该是：
"事情已经交给它了。"——这成为所有 UI 决策的第一原则。

## 十二条设计准则

### 一、核心模型：委托而非对话
界面不应让用户思考"我要怎么操作它"。进入禅模式 = 委托已完成，剩下的是等待与判断。

### 二、首页不是 Chat，是"当前世界"
不出现 "New chat / What can I help you with?"。打开直接看到进行中的事：

```
1866–1873：奥匈帝国餐桌研究
正在进行
已完成史料搜集、年代核验
当前正在处理 1873 年食品价格资料
最后更新：3 分钟前
```

心理模型从"我要找 AI 聊天"变成"我正在处理几件事，其中几件交给了 Agent"。

### 三、只有三个视觉层级
1. **事情**（最大）：标题、当前目标、正在形成的结果
2. **进展**（极简）："正在核对 1873 年维也纳食品价格资料"，而非 "Searching web..."
3. **介入**（按需）：仅当 Agent 需要人类决策时出现，且只给选项：

> 发现两组史料对 1872 年牛肉价格存在冲突。我可以继续寻找第三方资料，也可以暂时保留两种说法。

**UI 不告诉用户 Agent 在做什么，而告诉用户什么时候需要用户做什么。**

### 四、工程指标进入"地下室"
Token / KV Cache / Context / Model / Latency / Tool Calls / Reasoning —— 都不是主界面信息。
通过隐蔽入口（如 `● Working` 状态点）进入 Agent Console 才看到：

Model · Context · Tokens · Cost · Tool calls · Cache · Latency · Memory · Skills · Artifacts · Logs

**价值高 ≠ 应该出现在主界面。**

### 五、把"过程"压缩成"状态"
不展示系统日志流（Searching... / Opening 12 sources... / Reading PDF...），只展示认知进展：

> 正在寻找可靠的一手资料
> 发现两个互相矛盾的来源，正在交叉核验
> 已确认时间线，正在整理叙事

Agent 因此显得非常安静。

### 六、允许长时间工作
后台执行 → 用户离开 → Agent 完成 → 用户回来。回来第一屏直接交付：

```
完成了。
研究了 17 个来源 · 排除了 3 个不可靠说法 · 形成了 2,400 字初稿
有 1 个问题需要你判断
```

把"聊天"变成"工作交付"。

### 七、打扰预算
Agent 拥有自己的注意力预算。以下**一律不通知**：
找到资料 / 又发现网页 / 工具调用成功 / Token 超 50k / Agent 停顿 30 秒。

**只有三类事件可以打扰用户**：任务完成、出现阻塞、需要用户决策。

### 八、输入框不是控制面板
砍掉"模型/工具/文件/模式/Agent"选择器。用户表达意图，Agent 决定执行：

> "查一下这个说法。" → Agent 自己搜索
> "把刚才的研究整理成文章。" → Agent 自己使用已有上下文
> "看看 GitHub 上有没有类似实现。" → Agent 自己调 GitHub

Skill / Tool / Model 是 Agent 的内部能力，不是用户的操作负担。

### 九、保留方向盘
禅模式绝不等于"AI 决定一切"。保留四种明确的人类控制：

| 控制 | 语义 |
|---|---|
| **Pause** | 暂停当前工作（保留进度） |
| **Redirect** | 改变方向（steer 当前任务） |
| **Undo** | 撤销 Agent 的操作 |
| **Stop** | 彻底停止 |

尤其 **Undo** —— 用户真正害怕的不是 Agent 做复杂的事，而是"它替我做了，我还能不能拿回来"。解决这个问题，Agent 的自主程度可以大幅提高。

### 十、结果是"物"，不是"消息"
ChatGPT 的结果是一条消息；Agent 的结果是一个 **Artifact**：
文章 / 代码 / 研究报告 / 数据集 / 设计方案 / PR / PPT / 文件 / 完成的任务。

完成后的工作台中央是作品，不是聊天记录；"Hope this helps!" 式客服尾巴埋掉。

### 十一、信息按需显现
默认隐藏 → 上下文显现 → 用户主动深入：

> 平时："正在研究……"
> Agent 遇阻："需要你决定……"
> 完成："已完成。"
> 用户点击：展开过程
> 再点击：展开工程信息

### 十二、设计原则（八句 + 一句）
1. 不让用户管理 Agent
2. 不让用户管理上下文
3. 不让用户管理工具
4. 不让用户管理模型
5. 不主动展示内部运行指标
6. 只在需要人类决策时打扰人
7. 让用户随时可以暂停、改变方向、撤销
8. 把最终结果当成作品，而不是聊天消息

> **禅模式不是让 UI 变安静，而是让 Agent 承担更多噪音。**
